## 📊 Présentation

Projet d'analyse du catalogue Netflix réalisé avec Microsoft Power BI.

L'objectif est d'explorer le catalogue Netflix afin d'identifier les principales tendances concernant les films, séries, pays, genres et évolution du catalogue.

## 🎯 Objectifs

- Analyser la composition du catalogue Netflix
- Comparer les films et séries TV
- Identifier les pays les plus représentés
- Identifier les genres les plus représentés
- Analyser l'évolution du catalogue dans le temps
- Visualiser la répartition géographique des contenus

## 🛠️ Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Visualization
- Data Cleaning

## 🔄 Data Preparation

Les données ont été préparées avec Power Query :

- nettoyage des données
- traitement des valeurs manquantes
- transformation des types
- création de colonnes calculées
- préparation des données pour l'analyse

## 📌 KPI

Le dashboard présente notamment :

- Total Contents
- Nombre de films
- Nombre de séries
- Nombre de pays
- Nombre de réalisateurs

## 📊 Visualisations

Le dashboard contient :

- Répartition Films / Séries
- Top 10 des pays
- Top 10 des genres
- Évolution du catalogue Netflix
- Répartition géographique
- Filtres interactifs
